# 🌱 GreenHome AI

GreenHome AI is an AI-powered Sustainability Assistant built using **n8n**, **Google Gemini AI**, **Google Forms**, **Google Sheets**, and **Gmail**.

The workflow automatically monitors new Google Form submissions through a Google Sheets Trigger, eliminating manual intervention. User data, including electricity usage, water consumption, household size, and sustainability goals, is analyzed using **Google Gemini AI** to generate personalized recommendations.

The system estimates monthly utility costs, identifies potential resource wastage, provides energy and water-saving tips, and creates a weekly action plan. The generated report is formatted as HTML and delivered directly to the user's email using Gmail automation.

This project demonstrates AI workflow automation, API integration, event-driven architecture, prompt engineering, and no-code/low-code development using n8n and Docker.
